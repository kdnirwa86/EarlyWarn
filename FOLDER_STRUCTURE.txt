WHAT EACH FILE DOES
===================

app.py
------
Main Flask application that:
  1. Loads all 5 CSV files (data/)
  2. Calculates 3 signals from real data
  3. Validates signals across multiple sources
  4. Exposes REST API endpoints
  5. Serves the dashboard frontend

Example: Detects competitive price war by:
  - Reading competitive_deo_us.csv
  - Finding Old Spice -10.9% price
  - Validating with e-commerce data
  - Checking social sentiment
  - Returning 94% confidence signal

dashboard.html
--------------
Interactive frontend that:
  1. Shows 3 signals (left panel)
  2. Shows evidence data (right panel)
  3. Loads real data via API
  4. Displays actual CSV rows
  5. Allows filtering by data source

Data Files (data/*.csv)
----------------------
Real data from 5 layers:
  - circana_1000_rows_dummy.csv: Weekly sales, market share
  - competitive_deo_us.csv: Competitor pricing, promotions
  - ecommerce_deo_us.csv: Online prices, conversion rates
  - social_voice_deo_us.csv: Sentiment, trends, hashtags
  - macro_context_deo_us.csv: Inflation, confidence, regulations

DEVELOPMENT NOTES
=================

Adding CSV Files:
  1. Place in data/ folder
  2. Restart Flask
  3. No code changes needed

Modifying Signals:
  1. Edit backend/app.py calculate_signals()
  2. Update signal logic
  3. Restart Flask
  4. Dashboard updates automatically

Changing Frontend:
  1. Edit backend/templates/dashboard.html
  2. Save file
  3. Refresh browser (Ctrl+Shift+R)
  4. No Flask restart needed

Changing API:
  1. Edit backend/app.py routes
  2. Restart Flask
  3. Test with curl or browser


TROUBLESHOOTING QUICK REFERENCE
================================

Issue: "Connection Refused" (can't connect to localhost:5000)
Solution: Run scripts/DIAGNOSE.bat, then start Flask with scripts/START.bat

Issue: "CSV files not found"
Solution: Verify files are in data/ folder or project root

Issue: "Port 5000 in use"
Solution: Use: netstat -ano | findstr :5000, then kill process

Issue: "ModuleNotFoundError: No module named 'flask'"
Solution: Run: pip install flask flask-cors pandas
